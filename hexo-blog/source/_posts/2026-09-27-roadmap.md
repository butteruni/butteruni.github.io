## 产品方向

- **渲染效果平台**：在显式资源和管线契约上加入 PBR/NPR、GI、时序重建与 compute 效果。
- **MMD 内容产出**：PMX 模型、VMD 动作与相机、表情和物理共同驱动预览及序列帧输出。
- **GUI 与自动化共用能力**：编辑器和 CLI 使用相同的命令、状态查询和场景语义。

## 后续工作

### 场景与编辑边界

- 完整场景替换的资源 staging/swap；现有实例插入/删除事务不代表整场景替换已完成。
- 复核 PT 切换场景和零三角形路径的旧帧残留，具体复现边界见渲染器架构文档。
- 任意不同 Profile 的混合后处理合成，以及捕获深度/stencil 输入的实时化。
- 编辑器 diagnostics、animation/morph 查询的快照迁移，后续领域命令队列与窄接口。

### 渲染效果候选

以下是按需求启动的候选，不是全部进入执行的承诺：

| 方向 | 启动前提 |
|---|---|
| DDGI 探针体 | 以 [GI 对比协议](/2026/09/27/gi-test-scenes/)建立 SSGI / DDGI / PT 可比的场景和光照 |
| 通用时序重建与超分 | 在已有角色 TAA 之外，明确全场景 motion、深度、history reset 与输出契约 |
| 插帧 | 稳定的运动/深度输入和 present 生命周期 |
| froxel 体积雾 | 独立 compute 资源、光照输入及透射率合成约定 |
| XPBD 布料 | 独立模拟/变形输出、MMD 接入边界及可测性能预算 |
| CSM 阴影、SSAO 品质升级 | 有代表性的大场景或接触遮蔽需求及效果对比 |

### 按实测收益启动的优化

RenderGraph texture aliasing、multi-queue 和全局 pipeline cache 保持条件触发。
按需驻留、稳定拓扑和事务式 reload 已有实现；进一步优化依据
[性能预算与采样协议](/2026/09/27/gpu-performance-budget/)，不以增加框架层数作为目标。

## 范围与工作约定

完整 UE 编辑器、通用文档标签系统和 Play/Simulate 不在当前范围；CUDA interop 与
clustered lighting 暂不列入实施。采用 DX12 compute 的扩展优先使用现有数据与生命周期契约。

视觉改动通过 CLI 状态查询、截图及实际读取图片验证；构建和提交约定见仓库 `AGENTS.md`。
长期约束维护在专题文档及 [ADR](/2026/09/27/adr-readme/)，不再维护跨会话进度交接副本。
